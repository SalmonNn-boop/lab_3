# Справочник пользователей (REST API)

Интерактивное веб-приложение для загрузки, поиска и отображения данных пользователей и их публикаций с использованием публичного API JSONPlaceholder.

## Запуск приложения

Приложение не требует сборки или установки зависимостей и работает прямо в браузере.

1. Скачайте файлы проекта: `index.html`, `style.css`, `app.js`.
2. Убедитесь, что все три файла находятся в одной папке.
3. Откройте файл `index.html` в любом современном браузере (двойным кликом или через локальный сервер, например, VS Code Live Server).
4. Для начала работы нажмите кнопку «Загрузить пользователей».

## Результаты проверок

Все пункты из чек-листа выполнены успешно:

1. Загрузка пользователей (GET): 
   При нажатии на кнопку «Загрузить пользователей» появляется индикатор «Загрузка...», кнопка блокируется.
   После ответа отображаются 10 пользователей с именем, email и городом в виде карточек.
   
2. Поиск по имени (фильтрация): 
   При вводе «Leanne» список мгновенно фильтруется без новых HTTP-запросов (поиск не зависит от регистра).
   При вводе неизвестного имени появляется сообщение «Пользователи не найдены».
   Поиск заблокирован, если данные еще не загружены (появляется подсказка).
   
3. Публикации пользователя (GET):
   При нажатии «Показать публикации» отправляется запрос `?userId=ID` и выбранный пользователь подставляется в заголовок.
   В правой колонке отображаются заголовки и тексты первых трёх публикаций.
   
4. Обработка ошибок:
   Если в коде временно заменить `/users` на `/userz`, срабатывает `response.ok`, появляется аккуратное сообщение об ошибке `HTTP 404`.
   После возврата правильного адреса и повторного нажатия кнопки загрузка проходит успешно.
   Сетевые сбои также отлавливаются через `try/catch`.
   
5. Интерфейс и CSS:
   Приложение оформлено в мягкой пастельно-фиолетовой гамме.
   Использована сетка из двух колонок (слева — пользователи, справа — публикации).
   Отображены заглушки («Здесь появятся пользователи» / «Выберите пользователя...») для понятного пустого состояния.
